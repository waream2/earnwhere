LactSafe makes LactMed data easier for lactating people to search, retrieve, and understand. The project pairs accessible search with AI-assisted summarization so a user can move from a medicine name to a clearer explanation of the available safety information without having to parse the source material cold.

The project answers approximately 120 medicine safety questions per month, which makes it the rare side project with a real usage signal. It is also a useful proof point for the kind of applied AI work I care about: put the model near a structured, trusted body of knowledge, keep the user close to the source, and make the interface reduce friction without pretending to replace judgment.
